# Frontend (Vite + React)

Кратко: установка зависимостей и переменная **`VITE_API_URL`** указывают браузеру, куда слать запросы к Django API.

Полная пошаговая инструкция (backend + frontend, Docker, переменные окружения, обзор функций) — в **[README.md в корне репозитория](../README.md)**.

```bash
npm install
# создайте .env с VITE_API_URL=http://127.0.0.1:8000
npm run dev
```
